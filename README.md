# 🔐 Passwort Generator

Ein einfacher Passwort Generator mit Python und Tkinter.

Dieses Programm kann sichere Passwörter erstellen mit:
- Großbuchstaben
- Zahlen
- Sonderzeichen
- Benutzerdefinierter Passwortlänge

Außerdem kann das Passwort direkt in die Zwischenablage kopiert werden.

---

# 🚀 Funktionen

- Zufällige Passwörter generieren
- Passwortlänge auswählen
- Zahlen und Sonderzeichen aktivieren oder deaktivieren
- Passwort einfach kopieren
- Einfaches GUI-Design

---

# 🛠 Verwendete Technologien

- Python
- Tkinter
- Pyperclip
